一句话主线

最近两年的世界模型，不再只是“环境动力学模型”，而是在向一种通用基础设施变化： 它能把视频、语言、动作、3D 空间和记忆压进同一个可推演的状态空间，让 agent 在真实行动前先做内部实验。

所以这个领域最重要的提问已经从“模型能不能生成逼真的未来画面”，转向“模型能不能被行动控制、保持长期一致、 支持反事实推演，并真的提高下游任务成功率”。

一个容易踩的坑

world model 这个词现在被用得很宽：Sora/Genie/Cosmos 这类大视频模型会被叫作 world model； Dreamer/TD-MPC/JEPA 这类 latent dynamics 也会被叫作 world model；自动驾驶里的可控仿真器同样会被叫作 world model。

阅读时不要先纠结定义。更有用的切分方式是看它服务哪个功能：预测、规划、训练、评估、数据生成，还是长期记忆。

六条研究主线

Video / Interactive

视频生成走向可交互模拟

Sora 把视频模型包装成 world simulator，Genie 系列进一步强调 action-controllable 和 real-time interactive worlds。

  • Sora: 视觉数据统一成视频生成任务
  • Genie: 从无标注视频学习可玩的环境
  • Pandora: 用自然语言动作控制视频状态转移
Latent / JEPA

从像素转向可预测表征

这条线认为世界理解不一定需要像素级重建，关键是学到能预测、能规划、能泛化的 latent state。

  • TD-MPC2: decoder-free latent model-based control
  • V-JEPA / V-JEPA 2: 视频表征预测和物理推理
  • LeWorldModel: 端到端 JEPA world model
Robotics

机器人把它当训练场

机器人需要低成本试错。世界模型可以作为 learned simulator、policy evaluator、data engine 和 action planner。

  • UniSim: 学真实世界交互模拟器
  • Cosmos: 面向 Physical AI 的平台化 WFM
  • Ctrl-World / H-WM: 面向 manipulation 和长程任务
Autonomous Driving

自动驾驶是最现实落点

道路长尾场景稀缺且危险，world model 可以合成可控 edge cases，并服务预测、规划和闭环仿真。

  • Drive-WM: 多视角视觉预测和规划
  • OccWorld: 在 3D occupancy 空间建模演化
  • Waymo World Model: 官方产品化信号
LLM Agent

语言 Agent 需要可模拟环境

ReAct/ToT/Voyager 主要解决推理和行动编排；world model 补上“行动会怎样改变世界”的反事实推演层。

  • WorldGPT: MLLM 做跨模态状态转移
  • Language Agents Meet Causality: LLM + causal WM
  • Tree/option planning: 用 WM 做 MCTS/MPC
Evaluation

评测转向闭环成功率

现在的共识是视频真实感不等于世界理解，评测要看行动可控性、物理一致性、长期记忆和任务成功。

  • PhyGenBench / WorldModelBench: 物理和指令一致性
  • World-in-World: closed-loop task success
  • WorldArena: perception + functionality

怎么接到 LLM Agent / Memory Layer

Memory 保存历史状态、对象、约束、交互经验。
World Model 预测 action 之后状态如何变化，以及可能的 reward/risk。
Planner 在想象 rollout 里比较候选计划，例如 MCTS、MPC、Tree of Thoughts。
Actor 执行一个动作或 option，而不是把整条计划一次性押上去。
Verifier 用真实反馈校正记忆和世界模型，形成闭环。

如果把 ReAct 看作“边想边做”，ToT 看作“搜索思路树”，Voyager 看作“技能库 + 自我课程”，那么 world model 可以理解为下一层： 它不只让 agent 写出计划，而是让 agent 在可学习的环境模型里先试运行计划。这对长程任务、具身任务、多 agent 协作尤其关键。

关键问题对照表

研究问题 为什么重要 代表路线 观察指标
表示什么状态？ 像素很直观但不稳定，latent/3D/occupancy 更适合规划。 V-JEPA、OccWorld、Terra、LeWorldModel 长期一致性、3D 一致性、状态抽象是否保留因果变量
如何接收动作？ 没有 action conditioning，模型只能“续写视频”，不能做反事实规划。 Genie、Pandora、UniSim、Ctrl-World action following、controllability、policy-in-the-loop 成功率
能否长程保持一致？ agent 任务往往跨几十到几百步，误差会积累。 Genie 3、World-in-World、H-WM、memory-augmented WM 对象持久性、回访一致性、长程 rollout 退化速度
是否真的帮到任务？ 高 FVD 或漂亮视频不一定提升机器人或自动驾驶。 WorldArena、World-in-World、WorldEval task success、policy ranking correlation、data engine gain
能否从经验中修正？ 真实世界会打脸，世界模型必须能被观测反馈校准。 DECKARD、causal world model、model-based RL sample efficiency、OOD generalization、causal intervention accuracy

关键论文和资料卡片

通用视频/交互世界

Video Generation Models as World Simulators

Sora 的技术报告，重要性不在细节公开多少，而在它把“大规模视频生成 = 世界模拟器”的叙事推到了主流。

通用视频/交互世界

Genie: Generative Interactive Environments

从无标注互联网视频学习可交互环境，是“生成世界 + action control”的关键节点。

通用视频/交互世界

Genie 3

官方强调实时交互、720p、世界一致性和 promptable world events，代表 2025 之后的产品级方向。

语言动作 + 视频状态

Pandora

用自然语言动作控制视频世界状态转移，适合作为 LLM agent 连接 world model 的入口论文。

Latent / JEPA

V-JEPA / V-JEPA 2

不执着像素重建，而是预测 embedding；V-JEPA 2 进一步连接 physical reasoning 和 robot planning。

Model-based RL

TD-MPC2

虽然早于这波视频热潮，但它代表世界模型在连续控制里的务实路线：learned implicit world model + latent planning。

机器人

UniSim

把多源数据组织为 action-in / video-out 的真实世界交互模拟器，并展示纯模拟训练到真实机器人迁移的可能性。

机器人平台

Cosmos World Foundation Model Platform

NVIDIA 把 WFM 平台化，重点服务 physical AI 的合成数据、后训练和仿真。

自动驾驶

Drive-WM / OccWorld

一个从多视角视觉预测接规划，一个从 3D occupancy 空间建模驾驶场景演化，是 AV world model 的两种典型表征。

自动驾驶产业信号

Waymo World Model

说明生成式 world model 正从论文走向安全关键系统的仿真和长尾场景生成。

LLM Agent

WorldGPT / Language Agents Meet Causality

前者把 MLLM 组织成跨模态状态转移模型，后者把 LLM agent 和 causal world model 接起来。

评测

World-in-World / WorldArena

它们把评测重心从 open-loop 视频质量转向 closed-loop 任务成功、policy evaluation 和 data engine utility。

建议阅读顺序

  1. 先建立地图：From Masks to Worlds + World Model for Robot Learning。
  2. 看通用世界模拟：Sora 技术报告 -> Genie -> Pandora -> Genie 3。
  3. 看具身落地：UniSim -> Cosmos -> Ctrl-World / H-WM。
  4. 看自动驾驶：Drive-WM -> OccWorld -> DriveDreamer4D -> Waymo World Model。
  5. 最后看评测：WorldModelBench -> World-in-World -> WorldArena。这样能避免被“视频很漂亮”带偏。
